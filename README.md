### Introducción
El proyecto **Control de Accesos del Conjunto Residencial Los Robles** surge como respuesta a la necesidad de mejorar la seguridad y optimizar los procesos internos del conjunto.

Antes de la implementación del sistema, los registros se realizaban de forma manual, lo que generaba errores frecuentes, pérdida de información y demoras en la gestión de accesos.

### Descripción del Sistema
Sistema web de control de accesos compuesto por módulos de administración, vigilancia, turnos, propietarios, inmuebles, personal externo, control de accesos y novedades.

Permite la trazabilidad completa de ingresos y eventos, optimizando los procesos de seguridad del conjunto residencial.

### Aclaración Importante
El conjunto residencial, los nombres y las imágenes utilizadas **NO** corresponden a un conjunto real.  
Las imágenes son únicamente de uso ilustrativo y académico.

Sin embargo, el proyecto **sí cumple con las funciones reales de un sistema de control de accesos**, simulando correctamente los procesos que se implementarían en un entorno real.

### Problemática Principal
Antes del desarrollo del proyecto se presentaban las siguientes dificultades:

- Registros manuales con errores frecuentes  
- Dificultad para consultar historial de visitantes, vehículos y novedades  
- Pérdida de información o datos incompletos  
- Falta de control sobre vigilantes, propietarios y personal externo  
- Retrasos en los tiempos de respuesta del personal de seguridad  
- Vulnerabilidades en la seguridad por ausencia de información confiable  

### Solución Propuesta
La aplicación **Control de Accesos – Conjunto Residencial Los Robles** permite:

- Eliminación de errores en los registros  
- Historial de accesos completo y de rápida consulta  
- Información segura y sin pérdidas  
- Mayor control del personal de seguridad  
- Respuesta más rápida ante novedades  
- Reducción de vulnerabilidades en el conjunto residencial

### Introduction
The **Access Control System for the Los Robles Residential Complex** was developed in response to the need to improve security and optimize internal processes within the residential community.

Before the system was implemented, access records were handled manually, resulting in frequent errors, information loss, and delays in access management.

### System Description
A web-based access control system composed of modules for administration, security staff, shifts, residents, properties, external personnel, access control, and incident management.

The system enables full traceability of entries and events, optimizing security processes within the residential complex.

### Important Notice
The residential complex, names, and images used in this project **do not** correspond to a real residential complex.  
All images are for illustrative and academic purposes only.

However, the project **implements the real functionalities of an access control system**, accurately simulating processes used in a real-world environment.

### Main Problem
Before the development of the project, the following issues were identified:

- Manual records with frequent errors  
- Difficulty accessing visitor, vehicle, and incident history  
- Loss of information or incomplete data  
- Lack of control over security staff, residents, and external personnel  
- Delays in security staff response times  
- Security vulnerabilities due to unreliable information  

### Proposed Solution
The **Los Robles Residential Access Control System** provides:

- Elimination of record errors  
- Complete and fast access history  
- Secure information without data loss  
- Greater control over security personnel  
- Faster response to incidents  
- Reduced security vulnerabilities  

### System Scope
The system manages the following modules:

- Administrators  
- Security Staff  
- Shifts  
- Residents  
- Properties  
- External Personnel  
- Access Control  
- Incident Management  

Each module allows:
- Create  
- Read  
- Update  
- Delete  
- List
